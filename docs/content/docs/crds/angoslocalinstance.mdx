- **API version:** `angos.weebo.io/v1alpha1`
- **Scope:** Namespaced
- **Short names:** `ali`
- **Guide:** [Install via Helm](/docs/guides/install)

An Angos registry the operator runs in this namespace: its
`Deployment`, its configuration (rendered from this spec, its
repositories and identities) and the objects around them. `Ready` tells
whether its pods run the desired configuration.

## Example

```yaml
apiVersion: angos.weebo.io/v1alpha1
kind: AngosLocalInstance
metadata:
  name: my-localinstance
  namespace: team-a
spec:
  repositorySelector:
    namespaces:
      from: Same
```

## Spec fields

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `repositorySelector` | `object` | no |  | Which `AngosRepository`s the instance serves, and from which namespaces. |
