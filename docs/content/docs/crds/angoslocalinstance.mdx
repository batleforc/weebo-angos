- **API version:** `angos.weebo.io/v1alpha1`
- **Scope:** Namespaced
- **Short names:** `ali`
- **Guide:** [Install via Helm](/docs/guides/install)

An Angos registry the operator runs in this namespace: its
`Deployment`, its configuration (rendered from this spec, its
repositories and identities) and the objects around them. `Ready` tells
whether its pods run the desired configuration.

## Example

```yaml
apiVersion: angos.weebo.io/v1alpha1
kind: AngosLocalInstance
metadata:
  name: my-localinstance
  namespace: team-a
spec:
  storage:
    s3:
      endpoint: https://s3.example.com
      bucket: registry
      region: us-east-1
      credentialsSecretRef:
        name: registry-s3
  auth:
    tokenService:
      realm: https://registry.example.com/token
```

**Rules**

- more than one replica needs an S3 store (blobs and metadata): the pods share it — `self.replicas <= 1 || (has(self.storage.s3) && (!has(self.storage.metadata) || has(self.storage.metadata.s3)))`
- more than one replica needs worker.enabled: the background jobs go to a durable queue the worker drains — `self.replicas <= 1 || (has(self.worker) && self.worker.enabled)`
- `eventWebhooks`: event webhook names are unique — `self.all(w, self.exists_one(o, o.name == w.name))`
