- **API version:** `angos.weebo.io/v1alpha1`
- **Scope:** Namespaced
- **Short names:** `arepo`
- **Guide:** [Install via Helm](/docs/guides/install)

A repository of an Angos instance: the namespaces under its `prefix`,
who may pull, browse, push and delete there, where it caches from and
replicates to. Rendered into the instance's configuration by the
instance; `Ready` once every pod of the instance runs it.

## Example

```yaml
apiVersion: angos.weebo.io/v1alpha1
kind: AngosRepository
metadata:
  name: my-repository
  namespace: team-a
spec:
  prefix: dockerhub
  access:
    pull:
      - authenticated
  upstreams:
    - url: https://registry-1.docker.io
```

## Spec fields

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `access` | `object` | no | `{"browse":[],"delete":[],"pull":[],"push":[]}` | Who may do what (`access_policy`). |
| `downstreams` | `object[]` | no |  | Registries it replicates to (`[[downstream]]`). |
| `immutableTags` | `boolean` | no |  | `immutable_tags` (OR with the instance's). |
| `immutableTagsExclusions` | `string[]` | no |  | `immutable_tags_exclusions`: regexes. Not empty, it **replaces** the instance's list. |
| `index` | `object` | no |  | `index` policy: `default` (`index` or `skip`) and CEL rules on `image`; unset, the instance's. |
| `instanceRef` | `object` | no |  | The instance serving it: unset, the only one of this namespace. An instance of another namespace must accept this one (`repositorySelector.namespaces`). |
| `mirrorOf` | `string` | no |  | `namespace`: the `?ns=` value it answers to as a mirror (Docker's mirror requests name the upstream registry). |
| `prefix` | `string` | yes |  | The namespaces it covers: `<prefix>` and `<prefix>/…` (an OCI namespace: lowercase segments, no quote). **Immutable**: changing it would move the data out of the repository (delete and recreate). |
| `retention` | `object` | no |  | `retention_policy`: CEL rules on `image`; a matching one keeps the image (OR with the instance's), `angos prune` deletes the others. |
| `upstreams` | `object[]` | no | `[]` | Registries it caches from, tried in order (`[[upstream]]`): a pull-through cache, which refuses every push. |
