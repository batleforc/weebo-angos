- **API version:** `angos.weebo.io/v1alpha1`
- **Scope:** Namespaced
- **Short names:** `aid`
- **Guide:** [Install via Helm](/docs/guides/install)

A Basic identity of an Angos instance (`[auth.identity]`): a robot, a
CI, a scanner. The operator generates its password (or adopts one),
hashes it with Argon2id for the instance's configuration, and writes the
clear password to its targets once every pod of the instance accepts
it. Angos verifies a Basic password on every request (≈ 19 MiB and tens
of milliseconds each): workloads should rather use their
ServiceAccount's token (`auth.kubernetes`).

## Example

```yaml
apiVersion: angos.weebo.io/v1alpha1
kind: AngosIdentity
metadata:
  name: my-identity
  namespace: team-a
spec:
  registryHost: registry.example.com
  rotationDays: 90
```

## Spec fields

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `adoptSecretRef` | `object` | no |  | An existing password to keep (an identity moved from another tool), in a Secret of this namespace labelled `angos.weebo.io/credential: "true"`: read once, at creation. |
| `instanceRef` | `object` | no |  | The instance: unset, the only one of this namespace. An instance of another namespace must accept this one (`repositorySelector.namespaces`). |
| `registryHost` | `string` | no |  | The registry's public host (e.g. `registry.example.com`): adds a `.dockerconfigjson` key to the targets. |
| `rotationDays` | `integer` | no |  | A new password every this many days; the annotation `angos.weebo.io/rotate` (a new value) rotates it at once. |
| `secretTargets` | `object[]` | no |  | Where the credentials are written (keys `username`, `password`, and `.dockerconfigjson` with `registryHost`). Unset: the Secret `<name>-credentials` of this namespace. |
| `username` | `string` | no |  | The username (`identity:<username>` in access rules). Default: the CR's name. Unique on the instance, never an OIDC provider's name. |
